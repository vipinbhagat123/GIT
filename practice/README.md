# Practice Project

This folder is used to practice Git commands with a small backend-style structure.

## Suggested structure

- `backend/`
- `frontend/`
- `docs/`
- `scripts/`
- `tests/`

## Purpose

Use this folder to practice:

- `git status`
- `git add`
- `git commit`
- `git log`
- `git diff`
- `git restore`
- branching and merging later
